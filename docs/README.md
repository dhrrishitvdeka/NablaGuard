# NablaGuard documentation

The `math/` pages explain the numerical ideas exposed by the API. The
`research/` pages document implementation choices, limitations, and evidence
labels. Start with [the mathematical guide](math/README.md), then consult the
[measured performance baseline](performance.md) before enabling instrumentation
in a large training job. The [compatibility evidence](compatibility.md) states
the exact supported baseline and the boundaries of the v1.0 claim.
