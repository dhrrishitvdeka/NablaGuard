# NablaGuard v1.0.0

NablaGuard 1.0 is the first stable release of the PyTorch-first numerical and
gradient verification toolkit.

## Highlights

- Differentiable operator checks: forward, seeded VJP/JVP, double backward,
  central finite differences, nondeterminism, fuzzing, and failure shrinking.
- Eager numerical guard with bounded tensor evidence, overflow/underflow and
  cancellation checks, FP64 shadow execution, and precision auditing.
- Layered training capture, exact observable replay validation, monotonic
  first-bad-step bisection, and adjacent-boundary diagnosis.
- Multi-loss and bounded per-sample gradient geometry.
- Custom and built-in training contracts integrated with monitoring and capture.
- Console, JSON, self-contained HTML, JUnit XML, structured diffs, and a complete
  `nabla` CLI.

## Validation

- Python 3.12.13, PyTorch 2.13.0+cpu, Windows 11
- 99 passed, one CUDA-only test skipped, 88.19% line coverage
- Ruff and strict mypy clean
- Controlled benchmark: exact replay and bisection, 100% discovery and known
  shrink recovery in 20 seeded fixture runs
- Wheel build and metadata validation

## Compatibility boundary

CPU eager is the supported baseline. Compile-eager has smoke coverage. CUDA
tests run only when hardware is available; CUDA was not available in the release
environment. Native Triton introspection, distributed training, arbitrary
external state, and untrusted checkpoint replay are outside this release's
correctness claim.
